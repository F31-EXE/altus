# Альтус. Публичный фронтенд сайта-портала

ООО «Альтус», рекламно-производственная группа. Производство и монтаж
наружной рекламы и вывесок в Екатеринбурге.

Статический фронтенд на HTML и CSS без сборки. Контент, логотип и фотографии
перенесены с действующего сайта rg-altus.ru. Бэкенд подключается отдельно.

---

## Запуск

Проще всего просто открыть `index.html` двойным кликом: иконки, шрифты
и вёрстка работают и по `file://`. Спрайт иконок встроен прямо в страницы
именно поэтому: внешний файл браузер блокирует как cross-origin, и все
значки исчезают.

Единственное, что по `file://` не проверить, это отправку формы на реальный
бэкенд. Для полноценной проверки поднимите локальный сервер:

```bash
cd altus
python3 -m http.server 8080
# http://127.0.0.1:8080
```

Сборка, npm и node не нужны ни для разработки, ни для деплоя.
На проде достаточно отдать папку любым веб-сервером.

## Дизайн-система

### Палитра

Взята из логотипа заказчика. Фирменный цвет со слона это #373575, глубокий
индиго. Нейтралы построены на том же тоне 242° с низкой насыщенностью,
поэтому серый на сайте родственен логотипу, а не «просто холодный».
ТЗ просит синие и тёмные оттенки, индиго лежит в этой гамме.

Сам #373575 слишком тёмен для текста на тёмном фоне (1.76:1), поэтому для
интерактива взят осветлённый тон той же гаммы. Насыщенность намеренно
умеренная: логотип десатурированный, электрический неон-фиолет выглядел бы
чужим. Акцент ровно один, залочен на всю страницу. Тема одна, тёмная,
секции не инвертируются.

Сознательное решение: **свечение неона приходит с фотографий, а не из CSS.**
Ни одного blur-glow, неонового ореола и градиентной заливки по тексту.
Для компании, которая делает свет, сдержанный интерфейс работает лучше,
чем интерфейс, который сам пытается светиться.

Весь контраст проверен в браузере на вычисленных цветах, а не на бумаге:
30 пар текст/фон, все проходят WCAG AA, приглушённые цвета проверены на
самой светлой поверхности, где они встречаются.

### Шрифты

* **Unbounded** для заголовков. Широкий геометрический гротеск: буква как
  изделие, что для производителя вывесок уместнее нейтрального шрифта.
* **Onest** для текста и интерфейса.

Оба вариативные, оба с полной кириллицей, оба подключены локально.
Засечных шрифтов на сайте нет.

Кегль заголовка первого экрана ограничен сверху 3.35rem: Unbounded широкий,
и при большем размере заголовок перестаёт помещаться в две строки.

### Форма

Одна шкала скруглений на весь сайт:

| Что | Радиус |
|---|---|
| Поверхности, карточки, медиа | `--r-lg` 16px |
| Кнопки, поля, чипы | `--r-md` 10px |
| Мелкие метки | `--r-sm` 6px |

Скруглений вне шкалы нет, pill-кнопок нет.

### Раскладки

Семь секций, семь непохожих layout-семейств, ни одно не повторяется:

| Раздел | Семейство |
|---|---|
| Первый экран | асимметричный сплит со смещением медиа по вертикали |
| Наши услуги | 12-колоночная сетка, разные пролёты, две широкие карточки-скобки |
| Ход работы | липкая колонка слева, вертикальный рельс с этапами справа |
| Наши работы | мозаика, ряды 4+2 / 2+4 / 2+4 / 3+3 |
| Отзывы | горизонтальный ряд со scroll-snap |
| Блог | одна крупная запись плюс стопка мелких |
| Контакты | сплит «инфо и форма» плюс карта во всю ширину |

Подряд идущих сплитов «картинка и текст» больше двух не встречается.
Бегущих строк нет ни одной. Мелких капслок-меток над заголовками нет вообще.

### Движение

Каждая анимация отвечает на вопрос «что она сообщает»:

| Что | Зачем |
|---|---|
| Появление первого экрана лесенкой | задаёт порядок чтения в первую секунду |
| Появление секций при скролле | последовательное раскрытие по мере чтения, срабатывает один раз |
| Подъём кнопки на hover, нажатие на active | тактильный отклик |
| Открытие лайтбокса масштабом | переход состояния, связывает миниатюру и полный вид |
| Раскрытие текста услуги | показывает, что блок вырос, а не подменился |
| Спиннер и статусы формы | отклик на отправку |

Скролл нигде не перехватывается. Обработчика `scroll` на `window` нет:
положение шапки и появление блоков считает `IntersectionObserver`.
Всё движение выключается при `prefers-reduced-motion: reduce`.

## Что нужно от заказчика

Ниже всё, что сейчас стоит заглушкой. Каждое место помечено в коде
комментарием `TODO заказчик`.

### 1. Цены услуг

На старом сайте цен не было, поэтому в карточках стоит «Цена по запросу».
Слот под цену в разметке есть (`.svc__price`), поле готово под админку.
Когда появятся числа, уберите модификатор `svc__price--ask`, и цена снова
станет акцентной.

### 2. Соцсети и почта

На старом сайте не нашлось ни ссылок на соцсети, ни адреса почты.
Сейчас в блоке `.socials` в `index.html`:

* **ВКонтакте** и **Telegram** стоят заглушкой `href="#"`, нужны ссылки;
  ВКонтакте нужен обязательно, заявки из формы уходят именно туда
* **WhatsApp** собран из вашего номера: `https://wa.me/79120454444`.
  Проверьте, что мессенджер на этом номере действительно подключён
* ссылка на политику конфиденциальности стоит как `#`

Почты в контактах нет: не нашлась в исходниках. Если она есть, добавьте
блок `.contact-item` по образцу телефона.

### 3. Часы работы

На старом сайте не указаны. Если нужны, добавьте `.contact-item`
с иконкой `#i-clock`.

### 4. Блог

Раздел требуется по ТЗ, но на старом сайте его не было, поэтому три записи
демонстрационные. Заменяются на реальные, дальше приезжают из админки.

### 5. Логотип

Перенесён с сайта заказчика. В `assets/img/` лежат:

| Файл | Что это |
|---|---|
| `logo-original.png` | оригинал заказчика без правок, 1984x2349 |
| `logo.png` | светлый вариант целиком, для подвала |
| `logo-mark.png` | знак (слон) для шапки |
| `favicon-64.png`, `favicon-180.png` | значок вкладки, слон на фирменном индиго |

Светлый вариант сделан из оригинала перекраской по диапазонам светлоты:
корпус слона уходит в светлую лаванду, подложка в тень, бивни остаются
светлыми. Это понадобилось потому, что фирменный индиго на тёмном фоне даёт
1.76:1 и логотип был бы почти не виден. **Если у вас есть официальный светлый
вариант логотипа, пришлите его, он лучше автоматической перекраски.**

## Подключение бэкенда

Контактная форма сейчас работает на заглушке и показывает полный цикл
состояний: проверка полей, отправка, успех, ошибка.

Чтобы включить реальную отправку, добавьте адрес обработчика в разметку:

```html
<form class="form" data-form data-endpoint="/api/lead.php" novalidate>
```

Обработчик получает `POST` с `Content-Type: application/json` и телом:

```json
{ "name": "...", "phone": "...", "contact": "...", "message": "..." }
```

Дальше PHP пересылает заявку в сообщения сообщества ВК методом
`messages.send`. **Ключ доступа сообщества хранится только на сервере**
и на фронтенд не передаётся.

Чтобы посмотреть состояние ошибки без бэкенда, добавьте форме атрибут
`data-mock-fail="true"`.

## Лайтбокс

На весь сайт он один, в `assets/js/lightbox.js`. Его используют увеличение
фотографий услуг, галерея работ, сканы благодарственных писем и иллюстрации
в статьях.

Подключается к любому элементу через data-атрибуты:

```html
<button class="media-btn" type="button"
        data-lb-src="/img/big.jpg"
        data-lb-alt="описание для доступности"
        data-lb-title="Заголовок"
        data-lb-text="Описание под фотографией"
        data-lb-group="works">
```

`data-lb-group` объединяет снимки в галерею с листанием и счётчиком.
Без него открывается одиночное изображение.

Построен на `<dialog>`: фокус-трап, закрытие по Esc и возврат фокуса на
триггер работают средствами браузера. Листание стрелками, соседние кадры
предзагружаются, есть состояние загрузки и состояние ошибки.
Обработчик навешен делегированием, поэтому заработает и на контенте,
который в будущем приедет из админки.

## Что проверено

Проверка шла в реальном Chromium, не на глаз.

* 12 ширин экрана от 360 до 1920: горизонтального выноса нет нигде,
  шапка везде в одну строку и не выше 72px, кнопки не переносятся
* Первый экран помещается целиком, заголовок в две строки на десктопе
* 30 пар текст/фон проходят WCAG AA по вычисленным цветам
* Форма: пустая отправка подсвечивает 4 поля, заполненная проходит
  через состояние отправки к состоянию успеха
* Лайтбокс: открытие, счётчик `1 / 8`, листание стрелками, закрытие по Esc,
  снятие блокировки прокрутки, одиночное изображение без счётчика
* «Показать полностью» раскрывает текст и меняет подпись на «Свернуть»
* При `prefers-reduced-motion: reduce` не остаётся ни одного невидимого блока
* Сетки заполняются целиком: пустых ячеек в мозаике и в сетке услуг нет
* В консоли нет ошибок, все локальные запросы отвечают 200

## Известные ограничения

* **Благодарственные письма отредактированы.** В сканах закрыты банковские
  реквизиты контрагентов (расчётный и корсчёт, БИК), а в письме
  «Уральской слободы» ещё и личный мобильный телефон named сотрудницы.
  На старом сайте всё это было открыто. Оригиналы без правок остались
  в архиве старого сайта, если понадобится вернуть.
* **Сборки нет, поэтому шапка, подвал и спрайт иконок продублированы
  в пяти HTML-файлах.** При правке меню, контактов или набора иконок нужно
  пройти по всем пяти. Это осознанная плата за требование «html и css»:
  как только появится PHP, шапку, подвал и спрайт стоит вынести в `include`.
* Виджет Яндекс Карт светлый. Он оформлен как медиа-элемент в тёмной рамке,
  тема страницы при этом не меняется. Тёмная карта возможна через
  JS API Яндекса с ключом, если это понадобится.
* Административная панель в объём этой задачи не входила: сделан только
  публичный фронтенд. Разметка разделов уже рассчитана на подстановку
  данных из CMS, лайтбокс и раскрытие текста работают через делегирование
  и на динамически добавленных элементах.
