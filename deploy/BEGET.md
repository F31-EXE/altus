# Установка на Beget

Пошагово, для виртуального хостинга Beget. Займёт около получаса.
Скрипт `deploy/server-setup.sh` здесь **не нужен**: он для своего сервера
(VPS), а на хостинге Apache, PHP и MySQL уже стоят.

Что понадобится:

* аккаунт Beget и доступ в панель `cp.beget.com`;
* домен, привязанный к аккаунту;
* архив проекта (как скачать — в шаге 3).

Места, которые на Beget могут выглядеть иначе, чем описано, помечены
словом **«Проверьте»**: интерфейс панели время от времени меняется.

---

## 1. Сайт и PHP

1. Панель → **Сайты** → создайте сайт, например с папкой `rg-altus.ru`,
   и прикрепите к нему домен.
2. В настройках этого сайта выберите **PHP 8.3** (подойдёт любая от 8.1).

Beget создаст на диске папку `~/rg-altus.ru/public_html`. Это корень сайта,
то, что видно из интернета. Дальше мы подменим его на папку `public`
проекта, чтобы код и пароли от базы остались снаружи.

## 2. База данных

Панель → **MySQL** → создайте базу, например `altus`.

Beget допишет к имени ваш логин: получится что-то вроде `ivanov_altus`.
Пользователь базы называется так же, как сама база. Запишите три вещи:

* имя базы, например `ivanov_altus`;
* пользователя — то же самое;
* пароль, который задали при создании.

Сервер базы — `localhost`.

## 3. Загрузить проект

1. На GitHub откройте репозиторий, нужную ветку, кнопка **Code → Download ZIP**.
2. Панель → **Файловый менеджер** → зайдите в папку `rg-altus.ru`
   (не в `public_html`, а на уровень выше) и загрузите туда архив.

Распакуем его в шаге 4 через SSH, это быстрее, чем по одному файлу.

## 4. SSH: распаковать и подменить корень сайта

Подключитесь по SSH. Логин и пароль — те же, что от панели.
На Windows: PowerShell или PuTTY.

```bash
ssh ВАШ-ЛОГИН@ВАШ-ЛОГИН.beget.tech
```

**Проверьте** адрес сервера в панели Beget, раздел про SSH, или в письме
с доступами. Если SSH выключен, там же его можно включить.

Дальше команды по порядку. `rg-altus.ru` замените на свою папку.
В ней в этот момент должен лежать только архив и `public_html`.

```bash
cd ~/rg-altus.ru
unzip *.zip
rm *.zip
mv altus-* altus             # папка из архива называется по ветке, переименуем

# Корень сайта теперь папка public проекта, а не пустой public_html
rm -rf public_html
ln -s altus/public public_html
```

Получится так:

```
~/rg-altus.ru/
  altus/              проект: код, конфиг, база — снаружи
    public/           ← сюда смотрит сайт
  public_html  →  altus/public
```

## 5. Включить нужный PHP в консоли

Версия PHP, выбранная в панели, действует для сайта, но не для SSH.
В консоли по умолчанию может оказаться другая. Включите 8.3 на этот сеанс:

```bash
export PATH=/usr/local/php/cgi/8.3/bin/:$PATH
php -v                       # должно показать PHP 8.3
```

**Проверьте:** если `php -v` показывает не ту версию, посмотрите, какие есть:
`ls /usr/local/php/cgi/`, и подставьте свою.

Команду `export` нужно повторять при каждом новом входе по SSH.

## 6. Конфиг

```bash
cd ~/rg-altus.ru/altus
cp config/config.example.php config/config.php
nano config/config.php
```

Поменяйте эти строки (остальное оставьте как есть):

```php
'base_url' => 'https://rg-altus.ru',     // ваш домен, без слэша в конце
'debug'    => false,

'mail' => [
    'to'   => 'scharapov.wadym@yandex.ru',   // куда приходят заявки
    'from' => 'noreply@rg-altus.ru',         // ящик на вашем домене, см. шаг 9
],

'db' => [
    'host'    => 'localhost',
    'port'    => 3306,
    'name'    => 'ivanov_altus',    // из шага 2
    'user'    => 'ivanov_altus',    // то же самое
    'pass'    => 'пароль-из-шага-2',
    'charset' => 'utf8mb4',
],
```

Сохранить в nano: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.

Закройте конфиг от чужих глаз:

```bash
chmod 600 config/config.php
```

## 7. Таблицы, контент, администратор

```bash
php database/install.php
php database/seed.php
php database/create_admin.php "Ваше имя" ваша@почта.ru придумайте-пароль-от-10-символов
```

* `install.php` скажет «База … уже была, оставляю как есть» и создаст таблицы.
  Так и должно быть: базу создала панель, скрипт её не трогает.
* `seed.php` кладёт стартовый контент: услуги, работы, отзывы, блог.
* Пароль администратора нигде не хранится в открытом виде. Запишите его.

Все три команды можно запускать повторно: они ничего не задваивают
и не стирают.

## 8. HTTPS

Панель → **SSL-сертификаты** → выпустите бесплатный сертификат
Let's Encrypt на домен (и на `www.`, если он нужен).

**Проверьте**, есть ли там же переключатель «перенаправлять на HTTPS».
Если есть — включите. Если нет — напишите, добавлю правило
в `public/.htaccess`.

В конфиге `base_url` уже должен начинаться с `https://` (шаг 6).

## 9. Почта для заявок

Заявки с формы в любом случае сохраняются в админке, раздел «Заявки
с сайта». Письмо идёт сверх этого. Чтобы оно не попадало в спам:

1. Панель → **Почта** → создайте на домене ящик `noreply@rg-altus.ru`.
   Именно этот адрес указан в `mail.from` в шаге 6.
2. Панель → **DNS** → у домена должна быть TXT-запись SPF.
   **Проверьте:** если домен обслуживается DNS-серверами Beget, она
   обычно уже стоит и выглядит как `v=spf1 redirect=beget.com`.
   Если домен у другого регистратора, добавьте её там.

## 10. Видео: лимит загрузки

Админка принимает ролики до 512 МБ, но хостинг по умолчанию пускает
файлы куда меньше. Поднять лимит можно файлом рядом с сайтом:

```bash
cat > ~/rg-altus.ru/altus/public/.user.ini <<'EOF'
upload_max_filesize = 512M
post_max_size = 520M
max_execution_time = 300
max_input_time = 300
EOF
```

Действует через несколько минут.

**Проверьте:** у Beget на тарифе может быть свой потолок, выше которого
не поднять ни этим файлом, ни в панели. Если большой ролик не загружается —
сожмите его до 100–200 МБ (MP4, H.264: для сайта этого достаточно)
или уточните лимит у поддержки Beget.

## Проверка после установки

Откройте по очереди:

| Адрес | Что должно быть |
|---|---|
| `https://rg-altus.ru` | главная с услугами, работами, отзывами |
| `https://rg-altus.ru/blog` | три записи блога |
| `https://rg-altus.ru/admin` | вход в админку |
| `https://rg-altus.ru/robots.txt` | текст с адресом карты сайта на вашем домене |

Затем:

1. Войдите в админку, откройте любую услугу и сохраните её —
   проверка, что запись в базу работает.
2. Добавьте услугу с картинкой — проверка загрузки файлов. Потом удалите.
3. Отправьте заявку с формы внизу главной.
4. Откройте в админке **«Заявки с сайта»**. В колонке IP должен быть
   **ваш** адрес (свой можно посмотреть на 2ip.ru). Если там у всех
   заявок одинаковый адрес вроде `127.0.0.1` — напишите мне: тогда
   ограничение «5 заявок с IP за 30 минут» сработает сразу на всех
   посетителей, и это надо поправить.
5. Проверьте, пришло ли письмо на `mail.to`. Если нет — загляните в спам
   и перепроверьте шаг 9. Заявка при этом всё равно лежит в админке.

Демо-витрина прошлого разработчика `/site` тоже будет открываться.
Поисковикам она закрыта в `robots.txt`.

## Если что-то пошло не так

**Белая страница или «500 Internal Server Error».**
Временно включите в конфиге `'debug' => true`, обновите страницу — появится
текст ошибки. После исправления верните `false`: в режиме отладки
посетители видят внутренности сайта.

**«Не удалось подключиться к MySQL» при `install.php`.**
Неверные имя базы, пользователь или пароль в `config/config.php`.
Сверьте с панелью, раздел MySQL. Сервер — `localhost`.

**Сайт открывает пустую папку или ошибку 403 после шага 4.**
Ссылка `public_html` не сработала. Проверьте командой
`ls -l ~/rg-altus.ru/`: должно быть `public_html -> altus/public`.
Если ссылка на месте, а сайт не открывается, напишите в поддержку Beget:
«прошу сделать корнем сайта папку `rg-altus.ru/altus/public`» — это
стандартная просьба, её выполняют.

**Страницы кроме главной отдают 404.**
Не прочитался `public/.htaccess`. Проверьте, что файл есть:
`ls -la ~/rg-altus.ru/altus/public/` — точка в начале имени прячет его
от обычного `ls` и от некоторых FTP-клиентов при загрузке.

**Картинки в админке не загружаются.**
Права на папку загрузок:

```bash
chmod -R u+rwX ~/rg-altus.ru/altus/public/uploads
```

## Обновление сайта потом

Когда появится новая версия кода:

1. Загрузите новый архив в `~/rg-altus.ru`, как в шаге 3.
2. По SSH скопируйте его содержимое **поверх** папки `altus`. Папку
   целиком не удаляйте: в ней `config/config.php` и `public/uploads`
   с загруженными файлами, в архиве с GitHub их нет, и при копировании
   поверх они останутся на месте.

   ```bash
   cd ~/rg-altus.ru
   unzip *.zip -d new
   cp -r new/*/. altus/
   rm -rf new *.zip
   ```

3. Включите PHP (шаг 5) и выполните `php altus/database/install.php`:
   если в новой версии появились таблицы, он их добавит, существующие
   данные не тронет.

## После запуска

* Смените пароль администратора, если ставили временный.
* Добавьте сайт в Яндекс Вебмастер и укажите карту сайта:
  `https://rg-altus.ru/sitemap.xml`.
* Оставшиеся пункты от заказчика (цены, ссылка на MAX и т. п.) — в
  `README.md`, раздел «Что нужно от заказчика».
